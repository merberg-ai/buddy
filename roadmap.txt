Buddy v1.0 Project Roadmap
==========================

Project summary
---------------
Buddy is a Raspberry Pi 5 desktop AI buddy designed for Raspberry Pi OS Lite. It should use a modular plugin-first architecture where major capabilities can be added, removed, tested, enabled, disabled, installed from ZIP, or installed from GitHub.

Design pillars
--------------
1. Plugin-first architecture
2. Pygame face display instead of browser kiosk
3. Retro-terminal WebUI dashboard
4. Live web console on dashboard
5. Heavy structured logging
6. SQLite-backed memory and event history
7. Graceful failure handling
8. One broken plugin must not crash BuddyCore
9. Installable as an app or systemd service
10. Friendly install scripts with clear, verbose output

Core responsibilities
---------------------
BuddyCore should provide only the stable nervous system:

- FastAPI app shell
- WebUI shell
- Live console stream
- SQLite bootstrap
- Event bus
- Plugin discovery/loading
- Plugin manager WebUI/API
- Plugin permissions metadata
- Plugin config storage
- Plugin health/status/error tracking
- Logging infrastructure
- Safe-mode recovery
- Backup/debug bundle foundation

Plugins should provide features:

- Face display
- Emotion engine
- Voice pipeline
- Wake word
- Speech-to-text
- Text-to-speech
- Brain providers
- Vision/camera
- YOLO recognition/tracking
- Face recognition
- Servo/motion control
- Head tracking learning
- Memory summarization
- Integrations
- Log viewer
- System monitor

Milestone v0.1 - Framework Skeleton
-----------------------------------
Goal: runnable repo foundation.

Included:
- GitHub-ready repo structure
- README.md
- roadmap.txt
- requirements.txt
- FastAPI app
- Retro terminal dashboard
- Live WebSocket console
- Rotating file logging
- SQLite schema bootstrap
- Plugin manager
- Plugin manifests
- Plugin enable/disable/rescan/reload
- Plugin install from ZIP
- Plugin install from GitHub repo
- Default starter plugins
- Verbose install script
- Run script
- systemd install/uninstall scripts

Definition of done:
- App runs with ./scripts/run.sh
- WebUI opens on :8080
- Live console streams logs
- Plugins are listed
- Plugins can be enabled/disabled
- Bad plugin failure is logged and isolated
- SQLite DB is created automatically
- Service can be installed/uninstalled
